# Illustrations onboarding

Déposer ici les 3 illustrations SVG des slides d'onboarding :

| Fichier            | Slide                  |
|--------------------|------------------------|
| `notes.svg`        | « Suivez vos notes »   |
| `planning.svg`     | « Emploi du temps »    |
| `notifications.svg`| « Notifications utiles »|

Tant qu'un fichier est absent, le slide affiche un placeholder neutre — pas
besoin de relancer l'app après le dépôt, un hot reload suffit.

Dimensions de référence : carré (1:1), au moins 600×600. Fond transparent.
Palette à respecter : `ScolarColors.primary`, `ScolarColors.accent`,
`ScolarColors.ink` (voir `lib/theme/scolar_theme.dart`).
